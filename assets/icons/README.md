# Tarot Chain modifier icons

Compact 48×48 SVG assets for the reading side panel:

- `bound.svg` and `unbound.svg`
- `direction-upright.svg` and `direction-reversed.svg`
- Eight `moon-*.svg` lunar phase icons
- Twelve `zodiac-*.svg` zodiac season icons
- Seven `day-*.svg` planetary weekday icons

The icons use the existing Tarot Chain cream, yellow, red, blue, and navy palette. Expanded-panel artwork can remain separate from this small navigation set.
